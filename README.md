# Cinematic Web Architect

An installable Agent Skill for designing and building original, cinematic, scroll-driven, interactive websites.

**The full v8 master skill lives in one file:** [`skills/cinematic-web-architect/SKILL.md`](skills/cinematic-web-architect/SKILL.md).

## One-command installation

```bash
npx skills add namanahir128-stack/cinematic-web-architect --skill cinematic-web-architect -g
```

The Skills CLI may prompt you to select the coding agent(s) to install for. Restart the target agent session after installation.

For a project-only installation, omit `-g`. On Windows where symlinks are unavailable, use `--copy` if supported by your installed Skills CLI version.

## Quick test prompt

> Use cinematic-web-architect to build an original cinematic, scroll-driven specialty coffee shop website. Create a continuous Beans → Brewing → First Sip story, one memorable coffee-related interaction, and a tested desktop/mobile build. Produce runnable code and inspect the visual result, not merely a plan.

## What's inside?

- Creative direction, scene design, material/lighting quality and original art strategy
- Scroll orchestration, DOM/WebGL synchronization, 2.5D and 3D workflows
- Optional Blender, FFmpeg, browser automation and MCP guidance
- Visual QA, accessibility, motion continuity and performance checks
- Tool choice based on the actual available environment

**Installing this skill does not install MCP servers, Blender, paid APIs, or grant agent permissions.** Connect optional tools separately with explicit authorization. It does not guarantee any subjective design score.
